# dicta-action-harness

This folder is a harness for building the dicta action layer of a web site. Open
your AI agent in this folder and point it to the site's source code and test
environment. The agent studies the site and creates its layer: the site context
for `dicta-action-server` and the capability functions the site bundles for
`dicta-action-js`.

The guides, rules and checks for this work are not written yet.
